AI-Assisted Biomechanical Analysis of Baseball Pitching and Batting Technique

TURME analyses baseball pitching and batting mechanics from a single smartphone video, scores the movement against a professional reference, and turns the numbers into plain-language coaching feedback.

View reports GitHub repository

Section 01

Project

The problem

In baseball, mechanics decide both performance and injury risk, yet objective biomechanical analysis is locked behind million-dollar multi-camera stadium systems or left to a coach's naked-eye judgement. Faulty pitching mechanics cause not only weaker performance but serious shoulder and elbow injuries. Existing consumer apps only slow footage down or let users draw angles by hand — none of them automatically compare an amateur's body mechanics against a professional reference and explain what to fix.

Our solution

TURME is an end-to-end pipeline that runs on ordinary monocular 2D video. The athlete is isolated with object detection, the swing or pitch is automatically segmented into its biomechanical phases, and joint coordinates are extracted frame by frame to compute angles. Dynamic Time Warping aligns the user's movement with a professional MLB reference regardless of speed differences, and every angular deviation beyond tolerance is passed to a retrieval-augmented language model that writes constructive, actionable coaching feedback. The interface then plays the user's skeleton-overlaid video and the reference side by side, phase-synchronised and steppable frame by frame.
